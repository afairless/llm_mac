# llm_mac

Python boilerplate for running large language models (LLMs) on Apple Silicon (M-series) Macs.

---

## Table of Contents

1. [Features](#features)  
2. [Requirements](#requirements)  

---

## Features

- Simple Python interface to run LLMs on macOS  
- Support for local LLM runtimes (e.g., via MLX, `llama.cpp`)  

---

## Requirements

* macOS on Apple Silicon (M1, M2, M3, etc.)
* Python dependencies specified in pixi.toml
* Enough disk space to store your model(s)
* (Optional) Metal support for GPU acceleration if your LLM runtime supports it
